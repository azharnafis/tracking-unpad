# Frontend Lab KTNT UNPAD

Ini adalah frontend statis untuk tampilan landing page Lab KTNT UNPAD.

## Cara membuka

Buka file `index.html` langsung di browser.

## Tempat upload / simpan aset

- Foto hero laboratorium: `assets/images/hero-lab.jpg`
- Foto/peta bagian kontak: `assets/images/campus-map-placeholder.jpg`
- Logo resmi: bisa disimpan di `assets/images/logo-lab-ktnt.png`, lalu ganti elemen `.brand-logo` di HTML menjadi tag `<img>`.
- Icon: untuk sekarang icon layanan sudah berupa SVG inline di `index.html`, jadi tidak perlu upload file icon terpisah.

## Struktur yang disarankan

`backend` dan `frontend` dipisah supaya rapi:

```text
Tracking Unpad/
  backend/
  frontend/
    index.html
    lacak-sampel.html
    styles.css
    assets/
      images/
```
